# Theme origin

This directory is a project-local customization of
[hexo-theme-cactus](https://github.com/probberechts/hexo-theme-cactus).

- Upstream commit: `7a6074d830ac5d524582f142ac524c041077aad7`
- Upstream date: 2024-05-16
- License: MIT (see `LICENSE`)

Local changes redesign Cactus as the light-only Chiaro theme: a white reading
surface, layered lavender-to-pink orbital bands, compact avatar navigation,
local social icons, reusable note/project layouts, build-time MathJax, and a
compressed LXGW WenKai webfont.
